# Wykies Automation — Full GitHub Package (Public + Admin + Apps Script)

## Structure
- `/public` → GitHub Pages public website (wykiesautomation.co.za)
- `/admin` → GitHub Pages admin site (admin.wykiesautomation.co.za)
- `/apps-script` → Google Apps Script backend (CMS + PayFast + Admin)

## Deploy
### Public site
Create a GitHub repo for the public site and copy the **contents of `/public`** to the repo root.
Enable GitHub Pages (Deploy from `main` branch / root).

### Admin site
Create a second GitHub repo for the admin site and copy **contents of `/admin`** to repo root.
Enable GitHub Pages and set custom domain `admin.wykiesautomation.co.za`.

### Apps Script
See `/apps-script/README.md`.
