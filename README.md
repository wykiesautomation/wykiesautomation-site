## Deploy
1. Upload ZIP contents to repo root (`main`).
2. Enable GitHub Pages → Branch `main` → Folder `/`.
3. Optional: Deploy Apps Script and set `config.json` → `cms.appsScriptUrl`, `demo:false`.
